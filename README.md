# Resumen
Este proyecto es un ejemplo básico en Java diseñado para comprender los pilares fundamentales de la Programación Orientada a Objetos (POO). El ejercicio se centra en la creación de una clase molde (Libro) que aplica el principio de encapsulamiento,
y una clase de prueba (TestLibro) con el método main para manipular sus instancias.
# Características
Clase de Datos Pura (POJO): Define una entidad con atributos privados, asegurando que el estado interno del objeto esté protegido del acceso directo exterior.

Encapsulamiento de Atributos: Implementa métodos de acceso públicos (Getters y Setters) para leer y modificar las propiedades de manera controlada.

Constructor Parametrizado: Permite la inicialización completa del objeto con todos sus datos esenciales en una sola línea de código en el momento de su creación.

Método de Comportamiento (mostrarInfo): Encapsula la lógica de formateo de texto para imprimir los datos del libro limpiamente por consola.
